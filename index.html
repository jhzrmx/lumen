Lumen

Dependency-free alerts, prompts and toasts. Plain ES5, so it runs on anything from IE11 up.

Alerts

Icon shortcuts, same arguments as fire().

Confirm & decisions

Branch on isConfirmed, isDenied or dismiss.

Prompts & inputs

Validation messages show inline and keep the dialog open.

Async

Wait on a server call before the dialog closes.

Dismissal

Control how a dialog can be closed.

Behaviour

Timers, replacement, trusted HTML and position.

Toasts

Click a toast to dismiss it. Default timer is 3 s.

Toast positions

Set with the position option.

Customising

Themes and skins through setDefaults and mixin.
